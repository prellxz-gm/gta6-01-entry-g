Isla Verde is a 3D open-world crime game on a volcanic island: drive and steal cars, outrun a 5-star police dispatch with helicopters and roadblocks, complete 10 story missions and 5 syndicate contracts, and rise through the ranks with two crew members, territory income, stunt ramps, district standings, garage upgrades, radio stations, and street races — all playable in a desktop browser from static files.

## Run it

```sh
node main.ts
```

Then open `out/game/index.html` in desktop Chrome to play.
